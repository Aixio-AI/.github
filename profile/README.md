**Create and edit visuals with reusable creative Skills.** Create and edit visual
content with Aixio, then reuse your creative approach through Skills.
Aixio Layer v2 recovers editable text, shapes, images, and backgrounds from
flat designs where possible. Review recovered layers against the original before using them.
